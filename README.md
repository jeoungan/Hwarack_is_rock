# 화락제도 락이다

네온이 빛나는 학교 축제 밤무대에서 수달과 해골 댄서가 춤추는 4레인 웹 리듬 게임입니다. 제공된 Dance Dance Music의 100 BPM에 맞춰 무작위 노트를 누릅니다.

## 플레이

- 노트북은 **D · F · J · K**, 터치 화면은 아래쪽 해당 색 영역을 누릅니다.
- 휴대폰·태블릿 모두 가로와 세로로 플레이할 수 있습니다. 제목 화면에서 **휴대폰 가로·갤럭시 탭·노트북 사용 권장 / 세로 플레이 가능** 안내를 표시합니다.
- 세로 화면에서는 해골 댄서가 수달의 대각선 뒤쪽에 자리합니다. 휴대폰 점수판을 두 줄로 정리하고 넓은 네 터치 구역, 세로 결과 버튼, 화면 가장자리 안전 여백을 제공합니다.
- 오프닝 영상 → 제목 대기 → **시작하기 클릭·터치 또는 R** → Ready 3회 → Go → 120초 게임으로 이어집니다. 시작하기 아래 **챌린지 모드 · 2페이즈 바로 시작**으로 1페이즈를 건너뛸 수 있습니다. 바로 도전한 판의 1페이즈 점수는 0입니다.
- 제목 대기 중 수달이 DF·JK 자세를 천천히 번갈아 추며 가볍게 튑니다. 가로 화면은 제목 왼쪽, 세로 화면은 시작 버튼 아래에서 춤춥니다.
- 처음 15초는 한 개씩 연습하고, 이후 **DK·FJ·DJ·FK** 동시 입력과 더 빠른 노트가 등장합니다. 모두 양손으로 하나씩 누를 수 있는 조합입니다. DK는 양쪽 무릎 굽히기, FJ는 두 팔 V 자세로 수달과 해골이 함께 춤춥니다.
- 1페이즈는 120초에 최고 **2.0배속**에 도달합니다. 종료 후 노트는 사라지고 무대를 5초 더 보여준 뒤, 점수와 **도전하기 / 처음부터 다시**를 표시합니다.
- 이 5초 동안 수달과 해골이 **DF → JK → DF → JK → FJ**를 한 자세씩 1초 동안 추는 앙코르를 펼칩니다. 매 박자 발밑의 빛번짐과 작은 빛 입자가 터지고, 마지막 양팔 V 자세에서 더 크게 반짝입니다. 자동 안무는 점수·판정에 영향을 주지 않습니다.
- 도전하기를 누르면 2페이즈가 시작됩니다. **2.0배속에서 시작해 1분마다 +1.0배속**, 무작위 노트는 계속 생성됩니다. 제한 시간은 없습니다.
- 2페이즈는 **Miss 누적 5회**에 종료됩니다. Perfect·Special·Great·Good은 기회를 차감하지 않으며 누적 Miss를 줄이지도 않습니다. 동시 노트 실패는 한 번으로 계산하고 노트가 판정 범위에 없는 입력은 판정·점수·콤보·실수 횟수에 영향을 주지 않습니다.
- 2페이즈에는 버틴 시간(0.1초 단위), 점수, Miss 횟수를 표시합니다. 점수와 보너스는 페이즈마다 새로 집계하고 2페이즈 결과에는 1페이즈와의 합산 점수도 표시합니다. **도전 다시하기**는 2페이즈만, **처음부터 다시**는 1페이즈부터 시작합니다.
- 판정은 Perfect / Special / Great / Good / Miss, 점수는 5 / 4 / 3 / 2 / 1입니다. 실제로 놓친 노트만 Miss이고, 빈 구간 입력은 판정을 표시하지 않습니다.
- Perfect 5연속을 채운 뒤 6번째부터 연속 성공마다 1점을 추가합니다. 다른 판정이 나오면 다시 5연속을 채워야 합니다.
- Esc 또는 일시정지 버튼, 가로↔세로 회전은 현재 판을 멈추며 점수·시간을 유지합니다. 어느 방향에서도 이어할 수 있고 주소창 높이 변화만으로는 멈추지 않습니다. 노트북·태블릿의 다른 화면 전환도 일시정지합니다.
- 휴대폰에서 다른 앱으로 이동하거나 화면을 끈 뒤 돌아오면 제목의 **시작하기**로 돌아갑니다. 다른 페이지로 나갔다 뒤로 가기로 복원해도 진행 중이던 시간·점수는 초기화됩니다. 다시 시작하면 Ready/Go 후 **1페이즈 2분·0점**에서 시작하며 최고 기록·음향 설정은 보존합니다. 페이지를 새로 로드하면 오프닝부터 재생합니다.

## 음악과 박자

- 곡은 사용자가 제공한 The Mountain의 **Dance Dance Music**입니다(파일명 기준 표기). 원곡의 100 BPM과 0.465초 기준 박자에 노트를 배치합니다. 연습은 두 박자마다, 본무대·2페이즈는 한 박자마다 도착하며 노트의 방향은 매 판 달라집니다.
- 시작 클릭·터치/R 키로 음악을 켜고 실제 오디오 출력 시간으로 노트·판정을 맞춥니다. 일시정지 후 같은 위치에서 이어지며 상단 음악 버튼은 진행 위치를 바꾸지 않고 음소거합니다.
- 곡의 20.25~97.05초 구간(128박자)을 반복해 2분 무대와 무제한 도전에서도 박자를 이어갑니다. 1페이즈는 182개 판정이며 마지막 노트의 늦은 입력 시간까지 2분 안에 포함합니다.
- 음악 버전의 개인 최고 점수는 따로 집계합니다. 기존 공개 대시보드 기록은 보존하며 이전 버전을 켜 둔 참가자의 저장도 호환합니다.

## 카카오톡 공유

공개 게임 링크에 제목·설명·네온 수달 대표 이미지를 설정했습니다. 공유 미리보기용 이미지는 1200×630 JPEG 약222KB이며 게임 화면에서 별도로 내려받지 않습니다.

## 기록 저장과 TOP 10 대시보드

게임 결과에서 원하는 사람만 **기록 저장하기**를 눌러 이름 또는 별명과 기록을 저장합니다. 서버 응답을 확인한 뒤 완료를 표시하고 같은 판은 중복 등록하지 않습니다. 게임 안에는 순위표가 없습니다.

[별도 TOP 10 대시보드](https://hwarak-records.web.app/)는 Firebase Spark의 Firestore에서 각 페이즈 상위10개 기록을 읽습니다. 이름은 첫 글자+**로만 표시하고 점수·등급·생존 시간을 유지합니다. 1페이즈는 점수→정확도, 2페이즈는 생존 시간→점수→정확도 순입니다. 기본30초 자동 확인과 새로고침 버튼을 제공합니다. 같은 이름도 기록마다 별도로 집계합니다.

운영자는 Firebase 콘솔에서 수정·숨김을 관리합니다. 공개 페이지에는 관리자 코드·전체 이름·관리자 인증 정보가 없습니다. 기록의 전체 이름은 별도의 비공개 컬렉션에 저장하고 공개 접근을 차단합니다. Google Sheets와 Apps Script 연결은 제거했습니다.

무료 방식에서는 서버 시각·점수 합산·종료 조건·접근 권한을 확인합니다. 실제 입력 전체를 서버에서 재생하지 않으므로 완전한 치트 방지는 아닙니다. 무료 사용량 제한 시 저장/조회는 일시 제한될 수 있지만 게임 자체는 계속 진행됩니다.

## 로컬 실행과 수정

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://localhost:4173`에 접속합니다. 음악을 불러오려면 HTTP 서버 또는 공개 게임 주소로 접속하세요. `file://` 직접 열기는 음악 fetch가 제한될 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

26개 테스트는 판정·점수·동시 입력·연습 구간·2페이즈 누적 탈락/10분 연속 생성과 자동 성능 조절을 확인합니다. 빌드는 실제 웹에 필요한 파일만 `dist/`로 모으고 코드 파일에 내용 해시를 붙입니다. 미리보기 서버는 `dist/`를 제공합니다.

## 웹 배포

GitHub Pages 설정의 배포 소스는 **GitHub Actions**입니다. `main`에 올리면 `.github/workflows/pages.yml`이 테스트 → 빌드 → 배포를 진행합니다. Actions 화면의 **Deploy game to GitHub Pages**에서 수동 실행할 수도 있습니다. 배포가 끝나면 저장소의 Pages 설정과 해당 실행 화면에 게임 주소가 표시됩니다.

게임의 에셋은 상대 경로여서 저장소 이름이 붙는 하위 경로에서도 실행됩니다. 플레이어 계정 로그인이나 별도 음악 앱이 필요하지 않습니다. 음악은 게임에 포함된 MP3를 처음에 불러오며, 영상·그림·음악을 준비한 뒤에는 플레이가 네트워크 응답을 기다리지 않습니다.

## 성능과 에셋

- 실행용 음악을 포함한 전체 웹 빌드는 약 **7.52MB**입니다. 음악은 128kbps MP3 약 **1.76MB**입니다. 캐릭터 22장과 제목은 무손실 WebP, 배경은 고품질 WebP, 오프닝은 720p·24fps H.264/AAC MP4입니다.
- `asset-map.js`가 원본 이름과 압축 파일 이름을 연결합니다. 이 저장소는 실행용 압축본을 포함합니다.
- 움직이지 않는 배경·노트 경로를 캐시하고, 지속해서 프레임이 느려지면 입자 수·렌더링 해상도를 자동 조절합니다. **강한 빛번짐과 작은 빛 입자** 스타일, 판정 시간·점수는 유지합니다.
- 배포 파일은 내용 해시를 사용합니다. GitHub Pages에서는 서비스의 기본 캐시 정책이 적용되며 `_headers`는 Cloudflare Pages용 설정입니다.
- 실제 행사 기기에서 2분 한 판을 플레이하며 야외 가독성·동시 터치·후반 프레임·발열을 최종 확인하세요.

노트는 음악의 정박·반박자에 맞춰 연습0.6초/본무대·챌린지0.3초 간격으로 도착합니다. 1페이즈는 총365판정이며 반박자 이웃 노트는 다른 키를 사용합니다. 노트는 원래의 얇은 네온 막대으로 중앙 소실점에서 나타나고, 성공 즉시 접점의 빛번짐과 작은 빛 입자로 바뀝니다.
