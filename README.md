# 화락제도 락이다

네온이 빛나는 학교 축제 밤무대에서 수달과 해골 댄서가 춤추는 4레인 웹 리듬 게임입니다. 노래 없이 생성되는 박자와 무작위 노트로 플레이합니다.

## 플레이

- 노트북은 **D · F · J · K**, 터치 화면은 아래쪽 해당 색 영역을 누릅니다.
- 휴대폰·태블릿 모두 가로와 세로로 플레이할 수 있습니다. 제목 화면에서 **휴대폰 가로·갤럭시 탭·노트북 사용 권장 / 세로 플레이 가능** 안내를 표시합니다.
- 세로 화면에서는 해골 댄서가 수달의 대각선 뒤쪽에 자리합니다. 휴대폰 점수판을 두 줄로 정리하고 넓은 네 터치 구역, 세로 결과 버튼, 화면 가장자리 안전 여백을 제공합니다.
- 오프닝 영상 → 제목 대기 → **시작하기 클릭·터치 또는 R** → Ready 3회 → Go → 120초 게임으로 이어집니다.
- 제목 대기 중 수달이 DF·JK 자세를 천천히 번갈아 추며 가볍게 튑니다. 가로 화면은 제목 왼쪽, 세로 화면은 시작 버튼 아래에서 춤춥니다.
- 처음 30초는 한 개씩 연습하고, 이후 **DK·FJ·DJ·FK** 동시 입력과 더 빠른 노트가 등장합니다. 모두 양손으로 하나씩 누를 수 있는 조합입니다. DK는 양쪽 무릎 굽히기, FJ는 두 팔 V 자세로 수달과 해골이 함께 춤춥니다.
- 1페이즈는 120초에 최고 **2.0배속**에 도달합니다. 종료 후 노트는 사라지고 무대를 5초 더 보여준 뒤, 점수와 **도전하기 / 처음부터 다시**를 표시합니다.
- 이 5초 동안 수달과 해골이 **DF → JK → DF → JK → FJ**를 한 자세씩 1초 동안 추는 앙코르를 펼칩니다. 매 박자 발밑의 빛번짐과 작은 빛 입자가 터지고, 마지막 양팔 V 자세에서 더 크게 반짝입니다. 자동 안무는 점수·판정에 영향을 주지 않습니다.
- 도전하기를 누르면 2페이즈가 시작됩니다. **2.0배속에서 시작해 1분마다 +1.0배속**, 무작위 노트는 계속 생성됩니다. 제한 시간은 없습니다.
- 2페이즈는 **Great·Good·Miss 누적 5회**에 종료됩니다. Perfect·Special은 성공이며 성공했다고 실수 횟수가 줄지는 않습니다. 동시 노트 실패는 한 번으로 계산하고 빈 입력은 0점·연속 초기화만 적용합니다.
- 2페이즈에는 버틴 시간(0.1초 단위), 점수, 실수 횟수를 표시합니다. 점수와 보너스는 페이즈마다 새로 집계하고 2페이즈 결과에는 1페이즈와의 합산 점수도 표시합니다. **도전 다시하기**는 2페이즈만, **처음부터 다시**는 1페이즈부터 시작합니다.
- 판정은 Perfect / Special / Great / Good / Miss, 점수는 5 / 4 / 3 / 2 / 1입니다. 빈 입력은 0점입니다.
- Perfect 5연속을 채운 뒤 6번째부터 연속 성공마다 1점을 추가합니다. 다른 판정이 나오면 다시 5연속을 채워야 합니다.
- Esc 또는 일시정지 버튼, 가로↔세로 회전은 현재 판을 멈추며 점수·시간을 유지합니다. 어느 방향에서도 이어할 수 있고 주소창 높이 변화만으로는 멈추지 않습니다. 노트북·태블릿의 다른 화면 전환도 일시정지합니다.
- 휴대폰에서 다른 앱으로 이동하거나 화면을 끈 뒤 돌아오면 제목의 **시작하기**로 돌아갑니다. 다른 페이지로 나갔다 뒤로 가기로 복원해도 진행 중이던 시간·점수는 초기화됩니다. 다시 시작하면 Ready/Go 후 **1페이즈 2분·0점**에서 시작하며 최고 기록·박자음 설정은 보존합니다. 페이지를 새로 로드하면 오프닝부터 재생합니다.

## 카카오톡 공유

공개 게임 링크에 제목·설명·네온 수달 대표 이미지를 설정했습니다. 공유 미리보기용 이미지는 1200×630 JPEG 약222KB이며 게임 화면에서 별도로 내려받지 않습니다.

## 기록 저장과 TOP 10 대시보드

게임 결과에서 원하는 사람만 **기록 저장하기**를 눌러 이름 또는 별명과 기록을 저장합니다. 저장 응답을 확인한 뒤 완료를 표시합니다. 게임 안에는 순위 표나 대시보드 버튼이 없습니다.

별도 [TOP 10 대시보드](https://jeoungan.github.io/Hwarack_is_rock/ranking.html)는 로그인이나 열람 코드 없이 각 페이즈의 상위10개 기록을 보여줍니다. 표시 항목은 **첫 글자 + `**`로 가린 이름, 점수, S/A/B/C 등급, 생존 시간**입니다. 전체 이름은 대시보드에 전송하지 않습니다. 1페이즈는 점수순,2페이즈는 생존 시간순이며 같은 이름의 여러 기록도 각각 하나의 기록으로 집계합니다.

운영자는 별도 비공개 Google Sheet에서 기록을 수정하거나 표시를 해제/행 삭제합니다. 대시보드는 기본10초 간격으로 변경을 확인합니다. 기록 저장에는 인터넷 연결이 필요하며, Apps Script에서 같은 게임 규칙으로 입력을 재생해 점수와 종료 시간을 확인합니다. 중복 제출은 같은 기록으로 처리합니다.

## 로컬 실행과 수정

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://localhost:4173`에 접속합니다. `index.html`을 직접 열어도 실행할 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

19개 테스트는 판정·점수·동시 입력·연습 구간·2페이즈 누적 탈락/10분 연속 생성과 자동 성능 조절을 확인합니다. 빌드는 실제 웹에 필요한 파일만 `dist/`로 모으고 코드 파일에 내용 해시를 붙입니다. 미리보기 서버는 `dist/`를 제공합니다.

## 웹 배포

GitHub Pages 설정의 배포 소스는 **GitHub Actions**입니다. `main`에 올리면 `.github/workflows/pages.yml`이 테스트 → 빌드 → 배포를 진행합니다. Actions 화면의 **Deploy game to GitHub Pages**에서 수동 실행할 수도 있습니다. 배포가 끝나면 저장소의 Pages 설정과 해당 실행 화면에 게임 주소가 표시됩니다.

게임의 에셋은 상대 경로여서 저장소 이름이 붙는 하위 경로에서도 실행됩니다. 계정 로그인·외부 폰트·음악 다운로드가 필요하지 않습니다. 영상·그림을 준비한 뒤에는 플레이가 네트워크 응답을 기다리지 않습니다.

## 성능과 에셋

- 실행용 영상·그림은 약 **5.13MB**입니다. 캐릭터 22장과 제목은 무손실 WebP, 배경은 고품질 WebP, 오프닝은 720p·24fps H.264/AAC MP4입니다.
- `asset-map.js`가 원본 이름과 압축 파일 이름을 연결합니다. 이 저장소는 실행용 압축본을 포함합니다.
- 움직이지 않는 배경·노트 경로를 캐시하고, 지속해서 프레임이 느려지면 입자 수·렌더링 해상도를 자동 조절합니다. **강한 빛번짐과 작은 빛 입자** 스타일, 판정 시간·점수는 유지합니다.
- 배포 파일은 내용 해시를 사용합니다. GitHub Pages에서는 서비스의 기본 캐시 정책이 적용되며 `_headers`는 Cloudflare Pages용 설정입니다.
- 실제 행사 기기에서 2분 한 판을 플레이하며 야외 가독성·동시 터치·후반 프레임·발열을 최종 확인하세요.
