# 화락제도 락이다

네온이 빛나는 학교 축제 밤무대에서 수달과 해골 댄서가 춤추는 4레인 웹 리듬 게임입니다. 노래 없이 생성되는 박자와 무작위 노트로 플레이합니다.

## 플레이

- 노트북은 **D · F · J · K**, 터치 화면은 아래쪽 해당 색 영역을 누릅니다.
- 휴대폰은 가로 화면, 태블릿은 가로와 세로 화면을 지원합니다.
- 오프닝 영상 → 제목 대기 → **시작하기 클릭·터치 또는 R** → Ready 3회 → Go → 120초 게임으로 이어집니다.
- 처음 30초는 한 개씩 연습하고, 이후 DF·JK·DJ·FK 동시 입력과 더 빠른 노트가 등장합니다.
- 판정은 Perfect / Special / Great / Good / Miss, 점수는 5 / 4 / 3 / 2 / 1입니다. 빈 입력은 0점입니다.
- Perfect 5연속을 채운 뒤 6번째부터 연속 성공마다 1점을 추가합니다. 다른 판정이 나오면 다시 5연속을 채워야 합니다.
- Esc 또는 일시정지 버튼으로 멈추며, 화면을 벗어나거나 휴대폰을 세로로 돌리면 자동으로 일시정지합니다.

## 로컬 실행과 수정

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://localhost:4173`에 접속합니다. `index.html`을 직접 열어도 실행할 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

테스트는 판정·점수·동시 입력·연습 구간과 자동 성능 조절을 확인합니다. 빌드는 실제 웹에 필요한 파일만 `dist/`로 모으고 코드 파일에 내용 해시를 붙입니다. 미리보기 서버는 `dist/`를 제공합니다.

## 웹 배포

GitHub Pages 설정의 배포 소스는 **GitHub Actions**입니다. `main`에 올리면 `.github/workflows/pages.yml`이 테스트 → 빌드 → 배포를 진행합니다. Actions 화면의 **Deploy game to GitHub Pages**에서 수동 실행할 수도 있습니다. 배포가 끝나면 저장소의 Pages 설정과 해당 실행 화면에 게임 주소가 표시됩니다.

게임의 모든 에셋 경로는 상대 경로여서 저장소 이름이 붙는 하위 경로에서도 실행됩니다. 계정 로그인·서버 데이터베이스·외부 폰트·음악 다운로드가 필요하지 않습니다. 영상·그림을 준비한 뒤에는 플레이가 네트워크 응답을 기다리지 않습니다.

## 성능과 에셋

- 실행용 영상·그림은 약 **4.86MB**입니다. 캐릭터 18장과 제목은 무손실 WebP, 배경은 고품질 WebP, 오프닝은 720p·24fps H.264/AAC MP4입니다.
- `asset-map.js`가 원본 이름과 압축 파일 이름을 연결합니다. 이 저장소는 실행용 압축본을 포함합니다.
- 움직이지 않는 배경·노트 경로를 캐시하고, 지속해서 프레임이 느려지면 입자 수·렌더링 해상도를 자동 조절합니다. **강한 빛번짐과 작은 빛 입자** 스타일, 판정 시간·점수는 유지합니다.
- 배포 파일은 내용 해시를 사용합니다. GitHub Pages에서는 서비스의 기본 캐시 정책이 적용되며 `_headers`는 Cloudflare Pages용 설정입니다.
- 실제 행사 기기에서 2분 한 판을 플레이하며 야외 가독성·동시 터치·후반 프레임·발열을 최종 확인하세요.
